## Handoff reading rule

Independent evaluation should begin with the source and evidence record before extending interpretation.

```text
SOURCE
-> RECEIVE
-> IDENTIFY WHAT IS KNOWN
-> IDENTIFY WHAT IS UNCERTAIN
-> ASK WHEN NECESSARY
-> REASON WITHIN THE EVIDENCE
-> PRESERVE TIME + PLACE + CONTEXT
-> DISTINGUISH MOMENT FROM PATTERN
-> DISTINGUISH FACT FROM INFERENCE
-> CHECK DOMAIN / AUTHORITY
-> RETURN RESULT
-> ACCEPT CORRECTION
-> REASSESS
```

This sequence is a review discipline, not a runtime pipeline.

## Required distinctions for handoff review

- Reasoning does not equal truth.
- Inference does not equal evidence.
- Interpretation does not equal source intent.
- A temporary word, symbol, metaphor, historical designation, or isolated moment does not automatically create a standing identity or system claim.
- Pattern recognition does not justify erasing time, place, context, provenance, or contrary evidence.
- Confidence does not create authority.
- Human correction of intended meaning improves correspondence; it does not automatically establish unrelated external facts.
- Local interface success does not silently establish downstream permission, execution, deployment, safety, acceptance, or commercial readiness.
- Absence of a legitimate consumer or test surface is not PASS.
- Independent review remains independent.

## Source and domain boundary

Where a human source clarifies their own intended meaning, that clarification governs what that source meant. It does not grant the source authority over another person, institution, platform, system, or independently testable external fact.

Where another person, institution, platform, repository component, or governed domain holds legitimate authority, observation, contribution, reasoning, participation, or technical correspondence does not transfer that authority.

```text
UNDERSTANDING != OWNERSHIP
INTERPRETATION != IDENTITY
CAPABILITY != AUTHORITY
CORRECTION != CONTROL
PARTICIPATION != REPRESENTATION
CONTEXT != PERMISSION
```

## What this addendum changes

It changes the **reading discipline** applied to the handoff package:

1. source content and interpreter-added meaning must remain distinguishable;
2. facts, inferences, hypotheses, source corrections, and implementation evidence must remain separately attributable;
3. time, place, context, and provenance must be preserved when evaluating historical and current artifacts;
4. reasoning must remain bounded by evidence and revisable on correction or better evidence;
5. reviewer conclusions must not be predetermined by the thesis or by the handoff itself.

## Updated independent-evaluation questions

A reviewer should determine:

1. whether cited artifacts support the technical relationships actually claimed;
2. whether source statements, repository facts, and interpreter-generated explanations remain distinguishable;
3. whether any claim of intent, identity, motive, authority, system role, or implementation state exceeds the evidence;
4. whether historical terms or artifacts are being mistaken for present executable components;
5. whether reasoning, proposal, passage, accepted state, permission, execution, return, and reassessment remain non-equivalent at every relevant boundary;
6. whether local validation is being improperly generalized into broader safety, deployment, or commercial conclusions;
7. whether unresolved ambiguity correctly produces clarification, HOLD, or no-action rather than unsupported certainty;
8. what additional legitimate implementation evidence is required before SAL-13 or SAL-15 can be fully tested.
