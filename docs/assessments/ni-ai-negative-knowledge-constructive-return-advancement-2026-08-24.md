## Bounded advancement

Failure alone is not knowledge.

A boundary becomes useful negative knowledge when evidence establishes what should not be repeated under the demonstrated conditions.

Negative knowledge may narrow the future possibility space without dictating one mandatory answer.

Use:

```text
KNOWN INVALID PATH
-> CONSTRAIN THAT PATH WHEN THE PRESENT EVIDENCE SUPPORTS DOING SO
-> PRESERVE THE REMAINING POSSIBILITY SPACE
-> SELECT USING PRESENT EVIDENCE AND AUTHORITY
-> VERIFY
```

A past invalid path is not automatically a permanent universal prohibition. Time, place, environment, present evidence, and present authority remain relevant.

## Constructive return

Verified learning may return beyond internal correction in a form that supports people in understanding, connecting, coordinating, and identifying constructive possibilities.

Use:

```text
DIFFICULT EXPERIENCE
-> EVIDENCE-SUPPORTED UNDERSTANDING
-> CONNECTION
-> COORDINATION
-> CONSTRUCTIVE POSSIBILITY
-> HUMAN CHOICE / ACTION
-> POSSIBLE MOTIVATION OR POSITIVE OUTCOME
```

Human agency remains human. The system does not determine or guarantee another person's internal emotional state.
