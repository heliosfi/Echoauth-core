## Order 1 — Consistency across time

### Finding: SUPPORTED AS METHOD-LEVEL CORRESPONDENCE

The frozen notebook model preserves repeated operations:

```text
INPUT / OBSERVATION
-> NAME / DEFINE
-> DISTINGUISH
-> CLASSIFY
-> RELATE
-> COMPARE / TEST
-> IDENTIFY CONDITION OR LIMITATION
-> INTERPRET
-> IDENTIFY CONSEQUENCE
-> RESPONSE / NEXT MOVEMENT
-> NEW INFORMATION STATE
```

The later NI AI cognitive sequence preserves:

```text
SOURCE
-> ASSESS
-> LEARN
-> INTERPRET
-> UNDERSTAND
-> CONFIRM AUTHORITY
-> DECIDE
-> EXECUTE OR WAIT
-> VERIFY
-> CONCLUDE
-> RETURN
```

The sequences are not identical, but both preserve staged information handling rather than immediate action from raw input.

Method-level consistency is therefore supported in these areas:

- source/input preservation before movement;
- interpretation as a distinct operation rather than automatic truth;
- explicit testing of ambiguity, conditions, gaps, or discrepancies;
- preservation of unresolved states rather than forced progression;
- movement to a new state only after an intervening evaluation process;
- return/reassessment as part of the information lifecycle.

This supports longitudinal methodological correspondence. It does not prove direct descent from the notebook record.

These differences must not be smoothed away.

The later records add explicit requirements for:

- attributable and independently verifiable authority;
- exact subject, actor, scope, issuer, audience, validity interval, and permitted transition;
- distinction among understanding, authority, state, permission, and execution;
- fail-closed behavior;
- replay, idempotence, revocation, supersession, and conflict handling;
- namespace/version preservation;
- audit and evidence continuity;
- bounded execution crossing through CEG;
- explicit prohibition on hidden authority expansion.

These are substantive digital-governance specializations, not directly established by the notebook pages.

Therefore the longitudinal record contains both continuity and transformation:

```text
EARLIER METHOD-LEVEL PATTERN
-> later formalization
-> additional governance constraints
-> explicit authority separation
-> explicit fail-closed execution boundaries
```

The differences strengthen the assessment because they show that the later system is not being treated as a word-for-word transcription of the notebooks.

## Conclusion

The evidence supports a longitudinal methodological correspondence from the preserved physical notebook corpus to later digital governance artifacts at the level of information handling, uncertainty, staged movement, discrepancy preservation, time/place/currentness, and return.

The evidence also supports meaningful inconsistency: the later digital architecture introduces explicit authority, permission, audit, replay, currentness, fail-closed, and execution-boundary controls that are not established as formal contracts in the notebooks.

Accordingly, the strongest defensible conclusion is continuity of method with later formal specialization, not proof of direct technical transcription or causal provenance.
