## Reader-first explanation

A governed system does not need to move in one straight line. It may branch, revisit evidence, return to earlier checkpoints, or change representations. What keeps that movement governed is not the shape of the path but the preservation of source meaning, provenance, current authority, permission, consequence, and reassessment. The foundation provides the common reference; semantic fidelity preserves meaning across representation changes; execution remains separately bound; observed outcomes are reconciled; and return carries enough attributable understanding for the next state to be reassessed rather than assumed.

This state graph explains correspondence among already established governance relationships. It does **not** establish an implemented end-to-end runtime.

## Core architectural principle

```text
NON-LINEAR MOVEMENT != UNGOVERNED MOVEMENT
NON-LINEAR MOVEMENT != LOSS OF FOUNDATION
```

The architecture may revisit prior states, but movement does not authorize bypass of current authority, permission, freshness, consequence, or semantic-fidelity checks.

## Foundation definition

For this mapping, **FOUNDATION** means the attributable governing relationships against which later movement can be compared.

```text
SOURCE MEANING
-> GOVERNING INVARIANTS
-> RESPONSIBILITY BOUNDARIES
-> PROVENANCE
-> AUTHORITY / PERMISSION SEPARATION
-> INTERFACE CONTRACTS
-> RETURN / REASSESSMENT EXPECTATION
```

A foundation supplies reference and coherence. It is not itself an execution grant.

```text
FOUNDATION != PERMANENT AUTHORITY
FOUNDATION != RIGID SEQUENCE
FOUNDATION != COMPLETE IMPLEMENTATION
FOUNDATION != AUTONOMOUS AUTHORITY
```

A foundation does not need to prescribe every future path; it must preserve enough governing relationship for later paths to remain comparable, correctable, and reassessable.

## Reviewer-ready conclusion

The mapped architecture supports a non-linear governance model in which coherence depends on preserved relationships rather than a permanently fixed sequence. A foundation supplies an attributable reference for meaning, provenance, responsibility, authority, permission, execution consequence, return, and reassessment. The system may branch, revisit evidence, correct interpretations, or return to earlier checkpoints, but each consequential movement remains subject to current authority, permission, semantic-fidelity, and outcome-reconciliation boundaries. This permits adaptive navigation without treating flexibility as unrestricted authority. The model remains documentation-level: it clarifies how a governed runtime could preserve correspondence across non-linear movement, but it does not establish that the full runtime or its post-execution consumers are implemented.
