## Native responsibility boundaries recovered

### Adumetric

Upstream asymmetric responsibility. It forms governing meaning, reduces ambiguity, identifies exact requirements/evidence, and prepares bounded work.

It does not authorize itself, execute downstream work, or treat interpretation as permission.

### Hawk

Workflow-control responsibility. It preserves passage, routing, state, dispatch, handoff, return, currentness, and release posture.

It does not create upstream meaning, authority, permission, or downstream completion.

### Saloherm

Downstream hermetic responsibility. It performs only exact bounded work, preserves local integrity, produces the bounded result, returns it, and stops.

It does not reinterpret upstream meaning, widen scope, inherit authority, or choose the next lane.
