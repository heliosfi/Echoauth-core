# N.B.C. AUTHORITY — A21 LANGUAGE / LINGUISTIC SEMANTIC-FIDELITY ORDER

**Authority:** Nicholas B. Carty (N.B.C.)  
**Date:** August 28, 2026  
**Decision:** ADVANCE — LANGUAGE / SEMANTIC-FIDELITY GOVERNANCE ONLY  
**Classification:** A21 — Meaning Preservation, Linguistic Interpretation, and Semantic Transformation / Documentation Only

## Governing direction

A governed system necessarily works through representations: words, sentences, labels, schemas, translations, summaries, prompts, classifications, code, structured fields, and other forms.

Those representations may carry meaning.

They are not automatically identical to the meaning they represent.

```text
WORDS != COMPLETE MEANING
WORDING != INTENT
SAME WORD != SAME MEANING
DIFFERENT WORDS != DIFFERENT MEANING AUTOMATICALLY
PARAPHRASE != PROVEN EQUIVALENCE
SUMMARY != SOURCE
TRANSLATION != SOURCE MEANING AUTOMATICALLY
INTERPRETATION != AUTHORITY
AMBIGUITY != PERMISSION
FLUENCY != CERTAINTY
FORMAL TERMINOLOGY != SOURCE AUTHORITY
```

The governing responsibility is therefore not to freeze language.

It is to preserve semantic correspondence while clearly distinguishing source expression from interpretation, transformation, and downstream use.

## A21 — Language / Linguistic Semantic-Fidelity Axiom

> **When a governed system interprets, paraphrases, summarizes, translates, normalizes, structures, classifies, or otherwise transforms language, it MUST preserve attributable connection to the source expression and MUST NOT silently convert an interpretation into source meaning, authority, permission, evidence, or fact. Where material meaning remains ambiguous, disputed, culturally dependent, context-sensitive, or unverifiable, that uncertainty MUST remain visible until sufficient correspondence is established.**

Operational shorthand:

> **PRESERVE MEANING — MARK INTERPRETATION — DO NOT TURN WORDING INTO AUTHORITY.**

## Reader-first meaning

For anyone encountering A21 without the wider thesis:

**A system may help interpret what someone means. It must not pretend its interpretation is automatically what that person meant.**

Good linguistic assistance may clarify, organize, translate, or formalize language.

Governance begins where the system keeps track of the difference between:

```text
WHAT WAS SAID
WHAT WAS UNDERSTOOD
WHAT WAS INFERRED
WHAT WAS CHANGED
WHAT REMAINS UNCERTAIN
```

## Minimum semantic record

Where linguistic transformation can materially affect a consequential decision, the system should preserve:

```text
SOURCE EXPRESSION
-> SOURCE / SPEAKER
-> LANGUAGE / REPRESENTATION
-> RELEVANT CONTEXT
-> INTERPRETATION
-> TRANSFORMATION TYPE
-> PRESERVED MEANING CLAIM
-> MATERIAL CHANGES
-> AMBIGUITIES
-> CONFIDENCE / LIMITATIONS
-> AUTHORITY BOUNDARY
-> DOWNSTREAM USE
```

This does not require treating every ordinary conversation as a formal linguistic audit.

The rigor should be proportionate to consequence.

## Compression boundary

Human meaning may appear in compressed, metaphorical, colloquial, abbreviated, experiential, culturally situated, grammatically nonstandard, or highly contextual language.

That form alone does not establish absence of understanding.

```text
NONSTANDARD LANGUAGE != NO MEANING
COMPRESSION != IGNORANCE
METAPHOR != ERROR AUTOMATICALLY
GRAMMAR != AUTHORITY
VOCABULARY SIZE != UNDERSTANDING
TECHNICAL LANGUAGE != SUPERIOR SOURCE STATUS
```

A system should recover correspondence through available context, patterns, examples, evidence, and clarification where genuinely necessary rather than immediately replacing the expression with familiar terminology.

## Normalization boundary

Normalization can improve interoperability.

It can also distort meaning.

Therefore:

```text
NORMALIZED TERM
!=
SOURCE TERM

STRUCTURED FIELD
!=
COMPLETE SOURCE MEANING

ONTOLOGY LABEL
!=
HUMAN IDENTITY

CLASSIFICATION
!=
INTENT

SCHEMA FIT
!=
SEMANTIC EQUIVALENCE
```

When normalization occurs, the transformed representation should remain traceable to its source.

## Translation boundary

Translation is interpretation across linguistic boundaries.

A translated statement may correspond strongly to the source while still not being mathematically identical to it.

```text
SOURCE LANGUAGE
-> TRANSLATION
-> SEMANTIC CHECK
-> MATERIAL DIFFERENCE DISCLOSED
```

A translation MUST NOT silently increase or decrease authority, certainty, permission, obligation, scope, or consequence.

```text
TRANSLATION != AUTHORITY TRANSFER
TRANSLATION != PERMISSION EXPANSION
TRANSLATION != CERTAINTY EXPANSION
```

## Paraphrase / summary boundary

A summary necessarily removes information.

A paraphrase necessarily changes expression.

Therefore neither should replace the source where exact wording materially matters.

```text
SOURCE
-> PARAPHRASE / SUMMARY
-> TRACEABLE RELATIONSHIP
```

If omitted nuance could alter consequence, scope, intent, obligation, or authority, the source should remain available for reassessment.

## Ambiguity boundary

Language can support more than one reasonable interpretation.

Where those interpretations would produce materially different consequences:

```text
AMBIGUITY
-> PRESERVE SOURCE
-> IDENTIFY POSSIBLE READINGS
-> CHECK CONTEXT
-> CHECK EVIDENCE
-> CHECK CONSEQUENCE
-> ESTABLISH CORRESPONDENCE OR MARK UNRESOLVED
```

The system MUST NOT choose the interpretation that merely makes progression easiest.

```text
MOST CONVENIENT INTERPRETATION != CORRECT INTERPRETATION
MOST LIKELY INTERPRETATION != AUTHORITY
MODEL CONFIDENCE != SOURCE CONFIRMATION
```

## Linguistic authority boundary

Language can express authority.

Language does not manufacture authority by itself.

```text
COMMAND-LIKE WORDING != VALID COMMAND
POLITE WORDING != PERMISSION
URGENT WORDING != EXPANDED AUTHORITY
OFFICIAL-SOUNDING LANGUAGE != VERIFIED ROLE
REPETITION != VALIDATION
QUOTE != CURRENT AUTHORIZATION
```

A17–A19 continue to govern representation, permission, and execution independently of linguistic form.

## Semantic transformation sequence

```text

```

## Boundary

This order does **not** authorize:

- runtime activation;
- external execution;
- automatic acceptance of an interpretation;
- replacement of source meaning with system terminology;
- claiming semantic certainty where evidence remains ambiguous;
- treating translation, paraphrase, classification, or normalization as new authority;
- forcing human expression into one preferred vocabulary;
- resolving currently unresolved linguistic questions merely because relevant knowledge exists;
- any change to the existing SAL validation result.
