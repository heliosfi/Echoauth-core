## Purpose

Give each S1-S23 stabilizer / kernel module a bounded identity card without converting historical journal descriptions into current executable truth.

The accepted repository-wide rule remains:

- S1-S23 may process, classify, stabilize, reason, route, observe, score, or support.
- Their outputs are not authority.
- MCG/MPC governs state, mode, discipline, and permissibility.
- CEG governs movement sequencing.
- EchoAuth enforces permission.
- Execution remains separately bounded.

For every module, a bounded result/context may cross only while source responsibility remains with the source, destination requirements are independently satisfied, and governance/permission remain external unless separately established.

## Card-status vocabulary

- **HISTORICAL ROLE RECOVERED** — journal evidence establishes a historical description.
- **HISTORICAL TITLE RECOVERED** — dedicated journal filename/title establishes the module designation, but the precise present responsibility is not yet independently accepted.
- **CONFLICT / MULTIPLE HISTORICAL DESIGNATIONS** — more than one historical designation exists and must not be silently collapsed.
- **CURRENT INTERFACE UNESTABLISHED** — no accepted current exact input/output interface has been demonstrated by this registry.

## Common authority exclusions for every card

Unless a later accepted record independently proves otherwise, no S-module may by itself create or inherit:

- human or institutional authority;
- MCG/MPC state or permissibility authority;
- EchoAuth permission;
- CEG execution-order authority;
- runtime activation or kernel-mode activation;
- command dispatch or external execution authority;
- authorization for a later action;
- ownership, authorship, novelty, priority, or external validation.
